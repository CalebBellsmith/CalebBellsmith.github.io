Tilting Maze Platform

A study in rotational actuation and embedded controls.

Why

To integrate mechanical design and embedded systems while gaining experience with microcontrollers.

How

3D printed mechanical components, high-torque servos, and an ESP32 for functional, responsive control.

Specs

Custom-built circuitry and modular maze plates. Currently integrating Computer Vision for autonomy.

Embedded Control Systems

This project was a deep dive into PID control and mechatronics. The challenge lay in translating 2-axis joystick input into smooth servo movement without jitter. The modular plate system allows for different maze layouts to be swapped in. The next phase involves using OpenCV to track the ball's position in real-time, allowing the ESP32 to "solve" the maze automatically.
