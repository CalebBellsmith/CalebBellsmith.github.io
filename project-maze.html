Tilting Maze Platform

Why

To gain applicable experience with microcontrollers and rotational actuation, I developed this tilting maze as a way to integrate mechanical design and embedded systems.

How

I designed and 3D printed all mechanical components, utilizing high-torque servos, a potentiometer, and an ESP32 to create a functional, responsive system.

Specs

Every component, including the internal circuitry, was custom-built. Currently integrating Computer Vision via a webcam for autonomous navigation.

Embedded Control Systems

This project was a deep dive into PID control and mechatronics. The challenge lay in translating 2-axis joystick input into smooth servo movement without jitter. The modular plate system allows for different maze layouts to be swapped in. The next phase involves using OpenCV to track the ball's position in real-time, allowing the ESP32 to "solve" the maze automatically.
